Connect GitHub

Saving from the live site commits your changes to the site's GitHub repo, and GitHub Pages republishes in about a minute. The token is your key: it stays in this browser only.

  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repo.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
